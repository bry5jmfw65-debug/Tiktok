VIRALCLIP AI — GITHUB UPLOAD BUNDLE

Extract this ZIP. Upload these THREE files to the ROOT of your empty GitHub repository:
1. Dockerfile
2. render.yaml
3. viralclip-ai-complete.zip

Do not upload the outer ZIP itself. Upload the three extracted files above.
Then in Render choose New + -> Blueprint and select your GitHub repository.

After Render creates the service, set the environment variables shown in render.yaml.
See README.md inside viralclip-ai-complete.zip for the full setup and TikTok requirements.
